⚠️ Testnet Notice

DYNAX is currently an experimental testnet. It is not audited by any third party, runs on a single physical node, and should not be treated as a store of value. DYX has no monetary value. Use for testing and development only.

📋 Executive Summary

DYNAX is an experimental Layer 1 blockchain platform using SHA3-256 Proof of Work and ECDSA signatures, built and operated by a single developer with no external funding or infrastructure.

🔐 Core Principles

  • Decentralized by design: peer-to-peer node communication, no admin account
  • SHA3-256: block hashing algorithm
  • Proof of Work: auto-adjusting difficulty (Consensus V2)
  • Open Source: code published on GitHub
  • Self-custody: transactions are signed client-side; the node never receives private keys

🔐 Cryptography & Security

SHA3-256 Hashing Algorithm

  • Used for block hashing (distinct from Bitcoin's SHA-256)
  • NIST-standardized (FIPS 202)
  • Collision-resistant per current cryptographic consensus

ECDSA Signatures (secp256k1)

  • Private keys are generated and held by the user, in their own wallet software
  • Transactions are signed client-side before being broadcast
  • The node verifies signatures but never receives or stores private keys — endpoints that formerly accepted raw private keys over the network have been disabled

🌐 Network Architecture

Peer-to-Peer, No Central Server

  • 🔗 Nodes discover and connect to each other automatically
  • 📊 Every node holds a full copy of the chain and validates it independently before accepting it
  • 🧅 Nodes reachable only via Tor (.onion) can participate as peers, not just nodes with a public IP or domain

Current Limitations (Testnet Stage)

  • The network currently consists of a single known node — multi-node sync logic exists and is enabled, but has not yet been tested against an independent third-party node
  • The reference node runs on commodity mobile hardware, not dedicated server infrastructure, and its public URL can change over time
  • No independent security audit has been performed

💱 DYNAX DEX ● Disabled

An on-chain swap/liquidity feature was built using a constant-product (x × y = k) model, but it has been disabled pending a security rework: the original implementation did not verify ownership before moving pool balances. It will be re-enabled only once swaps require a signed, verified instruction from the liquidity owner.
